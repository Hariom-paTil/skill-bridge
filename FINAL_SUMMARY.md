## 🔌 API Integration

### Request Format
```json
{
  "targetedSkill": "string (required)",
  "knownSkills": "string (optional)",
  "experienceLevel": "string (required)",
  "learningGoals": "string (optional)",
  "timeCommitment": "string (required)",
  "preferredFormat": "string (required)"
}
```

### Response Format
```json
{
  "success": true,
  "data": {
    "targetRole": "string",
    "learningPath": [
      {
        "step": number,
        "topic": "string",
        "why": "string"
      }
    ]
  }
}
```
